Phone preview — one size for every builder screen

Same content, three sizes. All render the true 390 px device viewport (so wrapping matches what shoppers see) and are scaled to display — the trade-off is footprint vs. how large the text reads while you edit.

What builders do → Typeform, Involve.me, Jotform and the Shopify theme editor preview mobile at or near true device width (360–390 px) so the preview can't “lie” about wrapping. The usable floor is where body text renders below ~13 px on screen — past that it's hard to read while building. Recommendation: Balanced (≈344 px / 14 px text) — near-true size, comfortably legible, still fits a two-pane builder. Go True size if the builder pane is wide.
