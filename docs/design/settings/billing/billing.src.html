    Rules

    • Which features: only AI that runs every time a shopper uses the quiz. Product recommendations are set up once in the logic, so they carry no tag and use no credits.
    • Opt-in: every tagged feature starts off. The merchant turns it on, and the tag is on the control when they do.
    • Where: on the control that turns the feature on, and again at the top of that feature’s own settings. Nowhere else.
    • Wording and look: “AI”, the rate, and what counts as one use, for example “AI · 0.2 credit per results page”. No dollar amounts, because the price of a credit depends on the plan. A grey pill, the same on every feature; it states a cost and is not a warning.
    • One list: the tag, the “i” on Account and the usage record all read the same list of features and rates, so a new AI feature shows up in all three.
